# Urdu Language Specialist — Portfolio Website

A single-page website for a native Urdu translation, localization, QA, transcription, and voice-over freelancer — matching the structure you outlined: Homepage, About, Services, Portfolio, Experience, Testimonials, Contact.

## What's in here
- `index.html` — the entire site in one file (HTML, CSS, JS). No build step.
- `audio/` — put your voice-over demo MP3 files here (see below).

## Design notes
Bilingual typography is the running visual thread: every section heading appears in English with its Urdu translation set in Nastaliq script (via Google Fonts' "Noto Nastaliq Urdu") right beside it — a direct nod to the translation work itself. Deep ink + warm gold palette, "Newsreader" italic serif for headings, "Work Sans" for body text.

## Customize it — checklist
1. **Your name** — search for "Your Name" throughout (nav, hero not directly but footer/brand, contact) and replace.
2. **Photo** — swap the dark "PHOTO" placeholder box in the hero for a real `<img>` tag with your headshot.
3. **Hero copy** — headline, Urdu subtitle, and intro paragraph near the top of `<section class="hero">`.
4. **About** — your real background, bio, and stats (years experience, projects delivered, rating) in `#about`.
5. **Services** — the five rows in `#services` already match your list (Translation, Localization, Proofreading & QA, Voice-Over, Subtitling). Edit the descriptions to be specific to how you work.
6. **Portfolio**:
   - Translation/localization/subtitling samples currently link to `#` — point these at real writing samples, PDFs, or case study pages.
   - Voice-over demos use `<audio>` players pointing to `audio/demo-elearning.mp3` and `audio/demo-commercial.mp3`. **Add your real MP3 files to the `audio/` folder** with those names, or update the `src` paths to match your filenames. The small bar graphic above each player is decorative (auto-generated by the included script) — it doesn't reflect the actual waveform.
7. **Experience timeline** — update dates, roles, and descriptions in `#experience` to your real work history. Tool tags below it list example CAT tools/software — adjust to what you actually use.
8. **Testimonials** — replace with real client quotes (with permission), or pull from your Upwork reviews.
9. **Contact** — update the Upwork profile URL, email address, and LinkedIn URL in `#contact` (three link cards).

## Publish with GitHub Pages
1. Create a new GitHub repository (e.g. `your-username.github.io` for a root domain, or any name for a project site).
2. Upload `index.html` and the `audio/` folder (with your MP3s) to the root of the repo.
3. Go to **Settings → Pages**.
4. Under "Build and deployment," set **Source** to "Deploy from a branch," choose `main` and `/ (root)`, then **Save**.
5. GitHub will publish a live URL within a minute or two (e.g. `https://your-username.github.io/repo-name/`).

## Custom domain (optional)
Add it under "Custom domain" in the same Pages settings, then point your domain's DNS at GitHub Pages per [GitHub's guide](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site).

## A note on audio file size
MP3 demo files should ideally stay under ~10 MB each so the page loads quickly. Trim demos to 30–60 seconds if they're longer.
